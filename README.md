В данном проекте реализована база данных для хранения данных об авиаперелетах.

В папке requests 10 запросов с описанием.
Для создания базы данных локально нужно просто запустить sql-скрип builder.sql, расположенный в папке sripts.

Реализация заполнения данными имеет 3 варианта:
1) Заполнение случайными данными всех таблиц, для этого требуется просто запустить скрипт random_insert.py
2) Использование API для заполнения некоторых таблиц реально существующими данными, для этого нужно запустить inserting_flight.py, парсинг данных использует старонние библиотеки для подключения к сайту https://aviationstack.com/documentation.
3) Заполнение через CSV (реализована на основе реальных данных из интернет сети), заполняется только сущность Airports.


* пометка для проверяющего, iata-международный 2/3 символьный код для распознования воздушных судов, авиакомпаний и посадочных площадок, в данном проекте во многих таблицах использовался как ключ идентификации, поскольку в реальном мире так и происходит.
